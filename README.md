#Distance Calculator

A simple Python program that calculates the distance between two points on a grid using the **distance formula**:



\[
d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}
\]



---

## Features
- Prompts the user for coordinates `(x1, y1)` and `(x2, y2)`
- Uses the **math library** (`sqrt()` and `pow()`) for calculations
- Outputs the distance rounded to **two decimal places**
- Works for any numeric input provided by the user

---

##  How to Run
1. Make sure you have **Python 3** installed.
2. Save the program as `distance_calculator.py`.
3. Run in terminal or command prompt:
   ```bash
   python distance_calculator.py
